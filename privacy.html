"두꺼비가 알려주는 로또당첨번호"(웹사이트 brightbom.kr 및 안드로이드 앱 "두꺼비로또", 이하 "서비스")는 이용자의 개인정보를 소중히 여기며, 「개인정보 보호법」 등 관련 법령을 지킵니다.

1. 수집하는 개인정보

서비스는 이용자의 개인정보를 수집하거나 서버에 저장하지 않습니다. 회원가입, 로그인, 결제 기능이 없습니다.

3. 제3자 제공 및 처리 위탁

서비스는 개인정보를 제3자에게 제공하지 않습니다. 광고, 분석 도구(통계 수집), 추적 쿠키를 사용하지 않습니다.

웹사이트는 GitHub Pages(GitHub, Inc.)를 통해 제공되며, 서비스 제공 과정에서 GitHub가 접속 기록(IP 주소 등)을 보안 목적으로 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

4. 당첨번호 데이터

로또 당첨번호는 동행복권이 공개한 정보를 매주 자동으로 받아 표시합니다. 서비스는 동행복권과 관계가 없는 개인이 만든 비공식 서비스이며, 복권 구매·결제 기능이나 구매 페이지 연결을 제공하지 않습니다.

5. 아동의 개인정보

서비스는 만 19세 미만을 대상으로 하지 않으며, 아동의 개인정보를 수집하지 않습니다.

6. 이용자의 권리

서비스는 개인정보를 보관하지 않으므로 열람·삭제 요청 대상 정보가 없습니다. 기기에 저장된 정보는 브라우저의 사이트 데이터 삭제 또는 앱 삭제로 언제든지 지울 수 있습니다.
